# Seongsoo An — Academic Portfolio

Static academic website intended for `https://jipo1.github.io/`.

## Deploy
1. Create a **public** repository named `jipo1.github.io` under the `jipo1` account.
2. Upload `index.html` and `style.css` to the repository root on the `main` branch.
3. Under **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)` and save.
4. Open `https://jipo1.github.io/` after deployment completes.

## Before publishing
- Confirm all research/project descriptions and presentation details.
- Add verified email, portrait, and PDF CV if desired.
- Confirm exact degree name and undergraduate dates.
